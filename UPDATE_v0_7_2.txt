RR CALTRACKER v0.7.2 — MULTIPLE MEAL PHOTOS
Update for an existing v0.7.1 installation.

WHAT CHANGED
- Upload up to 5 photos in one uploader, or capture several using Add photo.
- All selected photos go into one Gemini analysis of the SAME unchanged meal.
- Start with a clear whole-plate photo. Other angles add context.
- Remove unwanted uploads in the native file list; captured views have Remove photo.
- The separate Extra photo & portion options panel is removed: no side-photo
  field, measured-plate controls or user-facing portion-method dropdown.
- Keep the optional meal description, per-food alternatives/gram corrections,
  kitchen-scale correction checkbox, today's totals, history and PDF reports.
- Changing, adding or removing a view clears the old analysis before a new one.

GITHUB STEPS
1. Extract the ZIP.
2. Open rrvelmineti01-code/rr-caltracker-demo on main.
3. From the repository's top-level file list, choose Add file > Upload files.
4. Upload and REPLACE these files from this update:
     app.py
     ui.py
     README.md
   You can also upload UPDATE_v0_7_2.txt for future reference.
5. Commit directly to main, for example: Add multiple meal photos in v0.7.2
6. Optional: open the existing tests folder, upload the five supplied test files
   there and commit. They are not needed to launch the app.
7. Reboot the existing Streamlit app and refresh your usual app link.

Keep your current browser_history.py/.js/.css, gemini_transport.py,
portion_estimator.py, report_export.py, requirements.txt, models, fonts,
.streamlit configuration and Secrets. No new dependency or API key is needed.
Do not upload the ZIP itself or put app.py inside a new nested folder.

LOCAL WINDOWS
Copy the updated top-level files into the existing app folder and replace them.
Copy the test files into its tests subfolder if desired. Run START.bat normally.

QUICK CHECK
- Upload one photo: it should work as before.
- Select two or more angles of the same unchanged meal and analyze once.
- Confirm food alternatives and gram edits remain visible below the result.
- Remove or change a photo: the old result must disappear until you analyze again.
- In Take photos, tap Add photo after each capture; remove unwanted views below.
- Save a reviewed meal to update today's totals, then check the PDF download.

LIMITS AND METHOD
Maximum 5 photos; 10 MB per raw photo. There is also a 12 MB combined limit after
images are resized/compressed. Invalid or excess files block the whole analysis;
exact duplicate uploads are included once. Do not mix unrelated meals/servings.

Gemini uses all views. The existing local weight model still uses the FIRST
photo; it does not combine multiple views into a measured 3D reconstruction.
The hybrid remains experimental. This update does not claim improved accuracy
or a validated precision percentage simply because extra photos are accepted.
Active captures are held temporarily in the app session, not saved to history.
