HOW THE NEW METHOD WORKS

The default is "Two-model estimate (experimental)" under Add meal details.
Gemini recognizes foods and supplies visual relative portions.
A bundled, trained FoodCNN weight-only CNN predicts WHOLE-DISH weight locally
from the primary photo. Python allocates that total using the visual shares.
USDA remains the source of nutrition per 100 g; reviewed grams determine totals.

This is not an independent trained per-food weight predictor. Mixed-meal splits
remain estimated. Plate diameter and the side photo inform Gemini; the local
weight model uses only the primary RGB photo. The model was trained on
Nutrition5k images and has not been validated on your phone or meals.
No 85%, 90% or improved accuracy claim is made.

Model error ranges are not calibrated, so the hybrid does not present Gemini's
old weight ranges as confidence intervals for the new model's output.
If the two initial estimates differ by more than 25%, the app asks you to review
the portions. If the model is missing, invalid or cannot run, the app clearly
warns that the displayed result uses visual portions instead.

Each new Analyze meal action sends a fresh Gemini request and runs fresh local
model inference. Model parameters/session are reused for efficiency; photos and
predictions are never cached for future analysis actions. The current result is
temporarily kept to support review, edits, PDF and nutrition-only recovery.

TEMPORARY GEMINI FAILURES

Recoverable timeouts, temporary DNS and selected server failures get at most
three attempts with short backoff and a shared time budget. Certificate errors,
authentication/access errors, model errors and unknown/daily quota errors are
not automatically retried. A short 429 rate-limit delay is respected only when
the provider explicitly supplies a suitable Retry-After hint.
Errors show a safe Gemini diagnostic code and attempt count, without keys,
raw provider bodies, photo data or private meal details.

SWITCH BACK TO VISUAL ESTIMATES

Open Add meal details > Photo portion method > Visual estimate, then Analyze.
To make visual estimation the default for all new sessions, optionally add
RR_PORTION_MODE = "visual" to Streamlit Secrets and reboot. Existing API keys
stay in Secrets. The app still makes fresh analyses in visual mode.
