FOR GITHUB / STREAMLIT:
- Open rrvelmineti01-code/rr-caltracker-demo on the main branch.
- Upload and replace the top-level files above.
- Add or replace .streamlit/config.toml at that exact path.
  You can use Add file > Create new file and enter .streamlit/config.toml,
  then copy in the supplied config contents if folder uploading is awkward.
- Upload the four test files into the existing tests folder (optional for running
  the app, recommended for preserving its checks).
- Commit the changes, then reboot your Streamlit app.
- Keep API keys only in Streamlit Secrets; no change to your saved keys is needed.
- Check Upload photo, Take photo, analysis, corrections, PDF, and History on a phone.

FOR LOCAL WINDOWS:
- Copy the files to the existing app folder as above.
- Run SETUP.bat to ensure Streamlit 1.65.0 is installed, then START.bat.
- HTTPS or localhost is required for direct camera capture. Uploading a photo
  remains available on a mobile device using a local HTTP network address.

PRIVACY CHANGE:
History now starts OFF and belongs to this browser only. It never synchronizes
across devices, and no app profile or personal-details form is created.
Enable it only if wanted; each meal still requires an explicit Save.
Retention can be 1, 7 or 14 days. Cleanup runs while open and on the next visit;
closed browsers cannot erase expired history automatically. Photos are not
included in saved history. Downloaded reports have their own lifetime.
Photos still go to Gemini for analysis; food-search terms go to USDA.

OLD HISTORY:
Old shared-server entries are not migrated or shown. The old meal_history.py
and meal_store.py modules are unused and can be removed. Old data files are
not automatically deleted. Export anything you need from the previous version
before removing its data folder. Never upload that folder to GitHub.

OPEN ACCESS:
The app has no accounts, but private Streamlit hosting can require viewer login.
If you want people to open it with no platform sign-in, set the Streamlit app's
sharing/access to public. You can keep the GitHub repository private.

Nothing has been changed in your deployed app until you upload this update.
