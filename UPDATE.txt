RR Drimatra Groq cloud update

INSTALL
1. Extract this ZIP.
2. In the existing GitHub repository used by Streamlit, replace app.py and ui.py with the files in this ZIP. Keep both filenames and their existing locations. Commit both files together.
3. Keep all other project files, requirements, models and secrets. This patch adds no Python dependencies. It is not a standalone app.
4. In Streamlit Secrets keep GROQ_API_KEY, GEMINI_API_KEY and USDA_API_KEY as separate top-level entries. Do not put keys in GitHub.
5. Groq is the new default. If RR_VISION_PROVIDER already exists, set it to "groq". Default GROQ_MODEL is "qwen/qwen3.8-27b", verified against Groq's documentation on 18 October 2026. Your account must have access. A different configured model must support vision and JSON mode.
6. Wait for Streamlit to redeploy, or reboot it if it does not pick up the commit. Confirm the page says Photo analysis: Groq.
7. Analyze one meal photo. Check the recognized foods and portions, USDA results, PDF download and optional history. This live call is not yet tested.

WHAT CHANGED
Groq cloud recognition and visual portion suggestions replace Gemini by default. Existing FoodCNN hybrid mass estimation and USDA calculations remain in use. This is a provider integration, not retraining, calibrated depth measurement or a verified accuracy improvement.
Groq mode supports 1-3 views of the same meal; Gemini mode retains 1-5. Extra photos are rejected, never silently discarded. Existing five-photo sessions may require removing two photos.
Instructions exclude utensils and ask the model to record identification uncertainty. Model-reported uncertainty is not calibrated.
Provider changes invalidate the current analysis. Existing review/history/PDF flows are retained. The page and PDF assumptions identify the selected provider. The privacy footer was updated from the matching v0.8.1 package.
No automatic cross-provider fallback: errors do not silently send photos to another provider. Groq errors show safe diagnostics without keys or provider response bodies. No automatic retry is performed for Groq calls.

ROLLBACK
Set the top-level Streamlit secret RR_VISION_PROVIDER = "gemini" and keep your valid GEMINI_API_KEY. Save and reboot if needed. The original Gemini transport remains in the repository and is used in Gemini mode. Alternatively revert the GitHub commit that replaced app.py and ui.py.

VALIDATION
Python syntax checks passed. Nine offline test methods passed, covering Groq dispatch and image payloads, photo limits, invalid/truncated output, empty meals, safe HTTP errors, timeouts and malformed JSON, secret lookup, Gemini rollback and provider-aware analysis signatures. Tests use mocked providers and do not establish model accuracy, live model access, browser layout or full integration with every deployed module.
